# Thinking in Pipelines

The first track asks whether TPF is worth considering. This one asks the harder question: once a pipeline exists, what does it own—and what must remain ordinary domain design?

These conversations cover application services, aggregates, cross-aggregate policy, domain events, bounded contexts, event sourcing, sagas, and the temptation to replace a useful language with framework vocabulary.
